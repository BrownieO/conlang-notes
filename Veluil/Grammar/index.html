Grammar

Verbs

Verbs act as programming functions. The first parameter is an object or subject complement. The last or only parameter is the subject. E.g.

Example function 1

  • mımtti memppu jjo
  • be human me
  • I am a human

Example function 2

  • la memppu di
  • ask human you
  • Asks you about a human

Nesting

Functions are nestable. For example, we can nest the previous function inside a "to be" one:

  • mımtti la memppu di jjo
  • be ask human you me
  • I am asking you about a human

Implicit "to be"

All messages get the verb "to be" implicitly at the start and a pronoun implicitly at the end. E.g.

Example message 1

  • (mımtti) memppu (jjo)
  • (be) human (me)
  • I'm a human

Example message 2

  • (mımtti) la memppu di (jjo)
  • (be) ask human you (me)
  • I am asking you about a human

Example message 3

  • (mımtti) la me bımppu di jjo (jjo)
  • (be) ask of name you me (me)
  • I'm asking your name
